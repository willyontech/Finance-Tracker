# Finance Tracker

Simple personal finance tracker for students.

## Features
- Add income/expense transactions
- View balance, total income, total expenses
- Delete transactions
- Data saved in localStorage
- Responsive design

## Files
- index.html - main page structure
- style.css - styling
- script.js - logic for adding, deleting, calculating balance
- spec.md / Data Model.md - specifications
- finance-tracker.report.json - CodeVibe authorship report

## How to Run
Open index.html in browser.
