# Finance Tracker - Student Edition

**Author:** Willy - Kigali, RW

**Storage:** localStorage - key app:data

- Add income/expenses in RWF
- Live balance calculation
- Data stays after refresh
- Mobile responsive
- Keyboard accessible (Tab navigation)
